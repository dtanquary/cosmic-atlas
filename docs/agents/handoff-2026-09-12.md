## How the GPU suites were run

Headless Playwright Chrome from `.cache/capture-tools` (Codex's install), runner scripts under `.cache/{lookback,footprint,share,tours}/`, model `.cache/cosmic-horizon/check.mjs`. Poll `#acceptance-results` until `status==='complete'`; reports land in `.cache/validation-<run>.json` via the Vite plugin. Two process lessons: Vite hot-reloads the page when anyone commits to `src/`, which corrupts a run in progress (bracket every run with `git log -1` and rerun on a mismatch); background-task completion notifications did not reliably wake agents, so run suites in the foreground with a hard timeout.
