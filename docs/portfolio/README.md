# Portfolio screenshots

Captured on 2026-09-16 from the production package (`npm run preview:pages`, the milestone-4 release build) in headless Chrome 153 on the Mac GPU at 1600×1000 CSS pixels, device scale factor 2, driven only through the public controls (orbit drag, Visit search, the Tours dialog and the Settings toggles).
