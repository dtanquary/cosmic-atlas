# Cosmic road trip image review

Requested by Dave on 2026-09-12: inspect images of every road-trip target, adapt the existing galaxy/cloud templates, preserve adopted size constraints, and retain the existing rendering when usable evidence is absent. The following is a visual-reference review, not a photometric fit or a recovered 3D structure. Implementation and GPU review are pending at this checkpoint.

| Stop | Images inspected and visual interpretation | Treatment |
| --- | --- | --- |
| Milky Way | [ESO optical panorama](https://www.eso.org/public/images/eso0932a/), ESO/S. Brunier: warm central light and obscuring dust seen from inside. There is no external photograph of our galaxy. | Preserve the existing sourced Milky Way reference and its continuous light/dust template. |
| Large Magellanic Cloud | [SMASH optical mosaic](https://noirlab.edu/public/images/noirlab2030a/), CTIO/NOIRLab/NSF/AURA/SMASH/D. Nidever, processing T. Rector/M. Zamani/D. de Martin: broad offset stellar bar, blue irregular outskirts and a prominent pink complex near one end. | Refine the cloud template with continuous bar light, patchy outskirts and localized Tarantula-inspired emission. Internal placement and depth remain assumed. |
| Small Magellanic Cloud | [SMASH optical mosaic](https://noirlab.edu/public/images/noirlab2030b/), same survey/processing credits: diffuse elongated body and scattered pink patches. Foreground globular clusters are separate objects. | Refine the softer stellar body and asymmetric wing. Do not incorporate foreground clusters or invent a Magellanic bridge. |
| Andromeda | [Hubble optical mosaic](https://esahubble.org/images/heic2501a/), NASA/ESA/B. Williams: continuous warm inner light, blue outer disk and long dark dust arcs. The jagged mosaic border is an image boundary. | Adapt the core continuous disk template with tight, partly annular dust/stellar structure; preserve the adopted M31 radius and sky ellipse. |
| M32 and M110 | [IAC wide field](https://www.iac.es/es/divulgacion/galeria-multimedia/elemento-multimedia/galaxia-espiral-de-andromeda-m31-y-galaxias-satelite-m110-y-m32), Daniel López/Alfred Rosenberg: compact smooth M32 and broader smooth M110. [NASA M110 detail](https://science.nasa.gov/mission/hubble/science/explore-the-night-sky/hubble-messier-catalog/messier-110/) shows localized dust in a cropped central field. | Use the existing smooth elliptical templates in the default appearance too. Preserve their separate adopted profiles; a central crop does not justify scaling dust across the entire dwarf. |
| Triangulum | [ESO VST optical/H-alpha image](https://www.eso.org/public/images/eso1424a/), ESO: loose broken arms, weak nucleus, many pink star-forming patches in a broad blue disk. | Adapt the continuous disk template with patchy open arms, faint center and localized emission. |
| NGC 3982 | [Hubble optical/H-alpha image](https://esahubble.org/images/opo1036a/), NASA/ESA/Hubble Heritage: intricate winding arms, dust filaments, blue associations, pink emission and a compact warm center. | Exact DESI identity `39633325333155389`: a continuous multi-arm disk, retaining the catalog size and ellipse. Image-caption distances do not replace the adopted redshift distance. |
| NGC 4026 | [Legacy Surveys DR9 image](https://www.legacysurvey.org/viewer?ra=179.8544868&dec=50.9616574&layer=ls-dr9&zoom=14), DESI Legacy Imaging Surveys: smooth narrow spindle with a brighter center; no visible spiral arms. | Exact identity `39633263488141603`: retain the existing measured smooth lenticular profile in the default appearance too. |
| Coma cluster | [Hubble field](https://esahubble.org/images/heic0813a/), NASA/ESA/Hubble Heritage, and [DSS2 wide field](https://esahubble.org/images/heic0813e/), NASA/ESA/Digitized Sky Survey 2: many separate galaxies, several luminous smooth ellipticals. | Preserve the current cluster. NGC 4874/4889 have no verified matching observations in this app's name index; a 2D field cannot supply their missing 3D catalog identities. |
| DESI survey | [Official DESI map and explanation](https://www.desi.lbl.gov/2024/04/04/first-cosmology-results-from-desi-most-precise-measurement-of-the-expanding-universe/), Claire Lamman/DESI collaboration (map image request unavailable locally). | Preserve the accepted 3D catalog and its actual sampling. Large-scale filaments are distributions of galaxies, not an image-derived luminous gas model. |

Reference images are linked for comparison, not redistributed as app assets. Color composites guide illustrative hues only; exposures, feature angles, unresolved depth, individual clouds and arm paths are not new measurements. Foreground stars, telescope spikes, mosaic edges and background nebulosity are excluded. Exact public identities select recipes, never rounded coordinates, row numbers or name resemblance. Unknown identities retain their current model. Both appearance modes retain these explicitly requested named treatments; Catalog types still restores classifications for other observations.
